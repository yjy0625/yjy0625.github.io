# Brief Summary

The Combined Reinforcement Learning via Abstract Representations paper (abbr. CRAR paper) introduces an architecture that combines model-based and model-free RL in a shared abstract state space for efficient planning, multi-task generalization, and transfer learning. The model consists of a state encoder $e$, model-based components (reward model $\rho$, discount factor model $g$, latent transition model $\tau$), and model-free components (Q-network $Q$). The model-based components are supervised by individual losses on each components ($\rho$, $g$, and $\tau$) and additional constraints to ensure that abstract representations of states do not collapse to trivial solution; the model-free component is supervised in a similar way as Q-learning except the Q-value is a multi-step estimation calculated with the help of the transition model. 

Below are comments of various sections of the paper. Note that these are not summaries and thus do not include comprehensive description of what's covered in the paper.

# Discussions

* **Discount Factor from Environment (2):** the setting of the paper states that the environment will return not only reward at each timestep of action execution, but also a discount factor between 0 and 1. Personally, I have not seen other works that has this component. Also, the paper doesn't emphasize this part a lot and didn't give examples for what the discount factor looks like in the experiment section. If anyone knows about this, comments are welcome.
* **Transition Dynamics Model (3.1):** the transition model operates in the abstract state space and models the *change* of state space (ie. $x' = x + \tau(x,a;\theta_\tau)$) rather than the mapping from current state to next state (ie. $x' = \tau(x,a;\theta_\tau)$). This sounds like the flow model in vision works and can be convenient if we want supervision on what kind of changes actions should bring about.
* **Entropy Maximization (3.2):** to prevent the model from coming up with trivial solutions of abstract state representation in low-reward scenarios, the authors propose a loss $\mathcal{L}_{d1}(\theta_e) = \exp(-C_d\lVert(s_1;\theta_e) - e(s_2;\theta_e)\rVert_2)$ that maximizes the distance between any sampled pair of states. This loss doesn't make a lot of sense because states when states are pulled apart in the latent space, those that are close in terms of reachability or optimality (according to whatever assumption we have on the state representation) are also pulled away from each other. It might be better to have a more specific loss to prevent trivial solution on learning a representation on states.
* **Cosine Similarity Loss for Interpretability (3.3):** to learn more interpretable abstract state representation, an interpretability loss is added that maximizes the cosine similarity between the first $n$ dimensions of dynamics model output and a *chosen* embedding vector $v(a)$ with the same dimension. In this way, the first few dimensions of abstract state change will be trained to match specified characteristics of actions. The problem here comes from excessive manual supervision. To apply this kind of loss, we must already have knowledge of what actions needs to be matched with which dimensions of state representation. This limits the applicability of this component. It would be nice if the model can automatically discover some salient relationships between actions and state changes rather than being manually instructed to model conform to these relationships.
* **Experiments (4):** the experiments shown in the paper consists of two toy experiments (labyrinth 4.1 and catcher 4.2) to show the interpretability feature of the model, a multi-task labyrinth experiment (4.3) to show performance in learning a distribution of complex tasks, and a transfer learning expeirment (4.4) in the same labyrinth environment to show the model's potential to be transfered to environments with different observations. My comments on (4.3) is that it doesn't show comparison with model-based planning using a stronger planning algorithm than random sampling like CEM (with the same amount of computation). As for (4.4), I believe there are a lot of potential of showing more in this section. The authors only ran experiments in which they transfer to the same environment with negative images as observations, which is not exciting. More useful would be to test on (1) transfering to the same environment with different lighting conditions and perspectives, only finetuning network $e$ or (2) transfering to different agent or environment dynamics with observations fixed, only finetuning transition model and policy.

# Takeaways

* The idea of combining model-based and model-free methods to learn state representations and planning is interesting.
* Learned state representations have potentials of being applied in a transfer learning setting where observations, agents, or transition dynamics are different.
* Transition models can be modeled by state change rather than mapping from current state to next state.
* We can possibly learn to maximize mutual information between representation and their effects to improve interpretability.
* State representations might be helpful in HRL setting where they can be used as subgoal representations.
